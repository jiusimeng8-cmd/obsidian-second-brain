# 安装

从零到能跑通一次真实写入，大约 20 分钟。请按顺序做，每一步都有验证方法。

## 0. 前置条件

| 组件 | 版本 | 检查 |
| --- | --- | --- |
| OpenCode / OpenChamber 桌面端 | 插件 API 为 `{ id, setup }` 的 V2 | 见第 3 步 |
| Python | 3.10+ | `python -V` |
| Node.js | 18+（MCP 服务需要） | `node -v` |
| Obsidian 笔记库 | 任意位置，建议 git 管理 | 一个绝对路径 |
| Obsidian MCP | `@bitbonsai/mcpvault` 或等价 | 见第 2 步 |

只需要本机回环访问，不需要开公网端口。

## 1. 放置代码

```powershell
git clone <this-repo> "$env:USERPROFILE\.config\opencode\second-brain"
```

最终目录：

```
~/.config/opencode/
├── second-brain/          ← 本仓库
│   ├── second-brain/      ← 后台程序
│   ├── plugin/            ← 插件源文件（待复制）
│   └── docs/              ← 文档与笔记库规则
├── plugin/
│   └── obsidian-memory.js ← 复制到这里
└── ...
```

复制插件与配置：

```powershell
Copy-Item "$env:USERPROFILE\.config\opencode\second-brain\plugin\obsidian-memory.js" `
          "$env:USERPROFILE\.config\opencode\plugin\obsidian-memory.js"
Copy-Item "$env:USERPROFILE\.config\opencode\second-brain\config.example.json" `
          "$env:USERPROFILE\.config\opencode\second-brain\second-brain\config.json"
```

然后编辑 `second-brain/config.json`：

- `vault` 改成你的笔记库绝对路径
- 先保持 `"dispatch": false`、`"validation_only": true`
- 在 `validation_sessions` 里填 3 个不同项目的会话 ID（可从客户端 URL 或会话列表里取 `ses_...`）

## 2. 配置 Obsidian MCP

程序通过 MCP 让整理会话读写笔记。任意实现都可，只要工具名包含 `read_note` / `write_note` / `patch_note` /
`search_notes`。以 `@bitbonsai/mcpvault` 为例，在客户端 MCP 配置里加一项（local stdio 或 remote HTTP 均可）：

```json
{
  "mcp": {
    "obsidian": {
      "type": "local",
      "command": ["cmd.exe", "/d", "/c", "npx.cmd", "--yes",
                  "@bitbonsai/mcpvault@0.16.0", "D:/你的笔记库"],
      "enabled": true
    }
  }
}
```

验证：在客户端里让任一会话读取一个笔记，能返回内容即通。若共用 HTTP 网关不稳定（日志出现 `ECONNRESET`），
把 `config.json` 的 `mcp_command` 设为上面这条命令（用 `{vault}` 占位），程序会只给笔记库目录换成本地 stdio。

> 注意：MCP 服务的启动命令在不同机器上差异较大（`npx` / `npx.cmd` / 绝对路径）。以你这台机器实际能跑通的为准。

## 3. 启用插件

把插件文件放到 `~/.config/opencode/plugin/` 后，客户端会热加载。日志里应出现 `loading plugin` 且**没有**
`failed to load plugin`。

插件只做一件事：检查 `second-brain/state/health.json` 的心跳，超过 90 秒就拉起后台进程。它不产生对话、
不监听端口、不在 UI 里刷消息。

手动启动（排查用）：

```powershell
powershell -File "$env:USERPROFILE\.config\opencode\second-brain\second-brain\start-worker.ps1"
```

## 4. 安装笔记库规则

本仓库 `docs/vault/` 下有三份可直接使用的文件：

```powershell
$vault = "D:/你的笔记库"
Copy-Item .\docs\vault\第二大脑.md        "$vault\00-入口\第二大脑.md"
Copy-Item .\docs\vault\AI-整理规则.md    "$vault\00-入口\AI-整理规则.md"
Copy-Item .\docs\vault\节点模板.md       "$vault\90-模板\第二大脑节点模板.md"
```

创建目录与索引（内容可以留空标题，程序与整理会话会按需补）：

```
01-看板/          看板（程序自动写 第二大脑处理进度.md）
70-个人/          目标、偏好、生活与长期关注
80-知识/          可复用方法与已验证经验
85-想法/          尚未承诺的想法
Inbox/            拿不准时的暂存
```

再在笔记库根目录的 `AGENTS.md`（或你的规则文件）里加入检索入口，让**业务会话**主动查记忆：

```markdown
## 跨会话记忆

长期信息统一存放本库。新任务涉及既往决策、进度、已知问题、长期目标或个人偏好时，
先按对象名/别名检索，读取 `00-入口/第二大脑.md` 或对应索引及最相关 1–3 篇笔记后再回答。
关键词无命中时换用旧名、目录、设备型号、关联主题。简单且无历史依赖的问题无需读库。
区分笔记记录日期与当前状态；服务健康等实时事实仍现场核验。
```

`docs/vault/第二大脑.md` 里已包含同样的路由规则，可据此裁剪。

## 5. 验证清单

按顺序检查，任一不通过就先修，不要继续：

1. **进程在跑**
   ```powershell
   Get-Content "$env:USERPROFILE\.config\opencode\second-brain\second-brain\state\health.json"
   ```
   `time` 应在近 90 秒内，`error` 为 `null`。

2. **只采集，不派发**（`dispatch:false`）
   等一两分钟，`health.json` 里 `sources.captured` 应增长，`jobs.pending` 开始出现。
   看板 `<vault>/01-看板/第二大脑处理进度.md` 会自动生成。

3. **打开派发**
   改 `"dispatch": true`。等一个任务完成（平均 1–3 分钟），看板出现「有实际核验写入的批次」。

4. **人工复核一次**
   打开看板里列出的笔记，确认：内容对得上原会话、有来源会话与消息 ID、没有把助手推断写成事实。
   核验只保证过程，事实正确性需要你抽查。

5. **跨会话检索**
   新建一个不相干的会话，问一个只存在于旧会话里的问题（例如「上次那个项目的部署地址是什么」）。
   不主动给上下文，看它是否按入口规则检索到正确笔记并说明记录日期。

6. **恢复能力**
   杀掉后台进程，等插件在 60 秒内拉起；或在 `processing` 状态时重启，确认同一任务继续而不是丢单。

全过之后再设 `validation_only: false`，进入长期回补。

## Linux / macOS

代码本身跨平台，差异只有三处：

- 文件锁：`storage.py` 在非 Windows 上使用 `fcntl.flock`。
- 启动：用 `python3 worker.py` 直接跑，或用 systemd user unit 代替插件守护。
- 路径：`config.json` 里的 `vault` 用绝对路径；MCP 命令改成对应平台的启动方式（`npx` 而非 `npx.cmd`）。

插件的 `SECOND_BRAIN_ROOT` 与 `SECOND_BRAIN_PYTHON` 环境变量在三个平台都可用。

## 卸载

```powershell
# 1. 停派发并停进程
#    config.json: "enabled": false
#    结束命令行包含 second-brain\worker.py 的 python 进程
# 2. 移除插件
Remove-Item "$env:USERPROFILE\.config\opencode\plugin\obsidian-memory.js"
```

笔记与台账都是你的数据，卸载不会删除。台账在 `second-brain/state/ledger.sqlite3`，
备份整个 `state/` 目录即可完整留档。
