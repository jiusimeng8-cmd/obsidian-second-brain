# 第二大脑节点模板

新节点 frontmatter 使用 `type / status / updated / aliases`，来源可写正文，以便同一节点保留多次更新。

## 这是什么

对象、主题或长期领域及其边界。

## 当前信息

事实、明确偏好、进度或想法；逐条注明“用户陈述 / 工具验证 / 助手建议 / 待确认”，记录发生时间；过时内容放历史。

## 下一步

只收录用户确认的计划或真实阻塞；建议另行标注。

## 来源与变更

- source_session: `ses_...`
- source_messages: `msg_起点` → `msg_终点`（长消息分段注明 part）
- recorded_at: ISO 时间
- occurred_at / verified_at: 原事实时间；未知写未知
- certainty: 明确陈述 / 已验证 / 待确认
- 本次变更及核验依据；新旧冲突保留双方来源。

## 关联节点

所属索引、主对象、相关项目或经验双链。
